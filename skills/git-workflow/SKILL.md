# Git 運用

## ブランチ
- ブランチの切り替え・作成は `git checkout` ではなく `git switch` を使う（エイリアス `gsw` / `gsc` / `gsd`）。
- ブランチ名はコミットログなどの文脈から、いい感じの名前を提案する。
- ブランチ名の先頭に `feature` などのプレフィックスは付けない。

## コミット・push
- コミットはなるべく細かい粒度で行う。コミット自体は都度確認しなくてよい。
- push は外向き操作なので、実行前に必ず確認する。
- コミットメッセージは英語・1行で簡潔に。

## モノレポ
- 親リポジトリではなく、各子リポジトリを対象にブランチを切る／作業する。
- 複数のサブリポジトリにまたがるときは、同一のブランチ名を使う。
- 作業を始める前に、対象のサブディレクトリへ移動してから行う。

## git 設定の好み（参考）
- `rebase.autostash`（stash に気付ける形が必須。可能なら autopop）。
- `diff.algorithm = histogram`。
- `rerere.enabled`。
