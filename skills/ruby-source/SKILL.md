# Ruby ソースコードの規約

対象は gem やアプリケーションなど、継続的に保守する Ruby ソースコード。
シェル上で一度動かすだけの使い捨てスクリプトは対象外（細かいスタイルは問わない）。

現状は最小限の規約のみ。今後、確認の上で追記していく前提。

## テスト・静的解析
- テストは RSpec を使う。
- 静的解析は RuboCop を前提とする。

## スタイル
- 文字列リテラルはシングルクォートで統一する。

## 方針
- 機械的に検知できる規約は、できるだけ RuboCop（`.rubocop.yml`）に寄せて自動で守る。
- RuboCop で形式的に検知できない設計・命名・意図レベルの規約は、この Skill に文章で記述して育てていく。
